## 已验证项

- Java 8 编译、打包成功；应用使用 Java 8 启动成功。
- 当前 18 项集成测试在 SQLite 和 PostgreSQL 均通过，0 失败、0 错误、0 跳过：`AuthIntegrationTest` 4 项、`ManagementIntegrationTest` 4 项、`AdminIntegrationTest` 3 项、`CampaignIntegrationTest` 7 项。
- 当前 4 项 Chromium 浏览器场景通过：现有 `frontend/e2e/portal.spec.ts` 的客户保存搜索与刷新回显、录音告知保存与刷新回显、错误登录及退出后的返回保护；新增 `frontend/e2e/java-core.spec.ts` 的任务创建编辑、待拨准备与查询、停止、返回首页。新增场景的一处空列表定位歧义已修正并单独复测通过。
- 并发准备测试通过：两个请求同时准备一个任务只创建一条通话。SQLite 使用单连接；PostgreSQL 使用 4 连接池验证行锁。SQLite 共享内存多连接会产生表锁冲突，因此开发配置已限制为单连接；多进程 SQLite 场景未验证。
- 任务预检测试覆盖拒呼名单、撤销同意、每日次数限制、按客户时区计算拨号时段、跨日事件次数。任务编辑保留已拨历史，停止取消计划重试时间，自动拨号及恢复尚未实现时返回 503 且不改变任务或通话状态。
- Python PBKDF2 密码格式测试向量验证通过；原有枚举、UUID 与时间字段在上述 PostgreSQL 测试范围内可读写。
- 原有前端 TypeScript 检查与构建通过；本轮仅重新执行了与已实现 Java 后端对应的浏览器测试。

## 未验证项、已知问题与环境限制

- 实际拨号、重试执行、回调处理、调度、话术流程、WebRTC、结果分析、报表等尚未完成 Java 迁移；对应完整链路未验证。任务启动仅支持 `auto_dial=false`，实际启动与恢复返回 503；前端正常启动按钮因此暂不能拨号。
- 当前应用禁止以生产模式启动，并以未就绪状态标记部分迁移；不可部署替换生产后端。
- 原数据库全部增量迁移、历史数据、并发事务、压力、真实线路与真实设备未验证。当前结果仅适用于隔离开发环境。
- API 结构验证与 Python 行为尚未完成全量差异验证；部分嵌套对象和跨字段校验仍需补齐。
- 用户规则中的电商链路（门店、购物车、支付）不属于本项目。外呼链路“登录 → 客户 → 话术 → 外呼任务 → 拨号 → 回调 → 通话记录 → 报表”已验证登录、客户、任务准备与待拨记录查询；真实拨号、回调、结果分析、报表及完整链路未验证。任务表单使用已发布话术流程的完整入口尚未验证。
