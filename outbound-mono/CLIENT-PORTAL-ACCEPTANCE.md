## 认证与隔离

- 企业账号独立表 `client_user`，令牌带 `typ=client`，只能访问 `/api/v1/client/**`（`ClientJwtFilter`）。
- 员工 JWT 域（`JwtRealm`）拒绝任何带 `typ` 的令牌；员工令牌、租户 API Key 访问企业接口返回 403。
- 企业身份不复用 `Identity`：`Identity.user()==null` 在原系统表示租户 API Key，可读全租户数据。
- 越权访问其他企业或未分配的线索统一返回 404。

### 全量回归

2026-10-31 本机全量 `mvn -B verify`：单元测试 338/338 通过；集成测试 351 项，349 通过、2 项失败：

- `DataLayerReplayIT.v22TrialHistoryKeepsUnknownMeasurements`：迁移数断言未计入新增的 V29（6 → 7）。修正后单独复跑 3/3 通过。
- `BailianTrialIT`：在本机时好时坏，与本次改动无关。同一时段在干净的 `origin/main` 上单独运行，失败的是 `optionalReviewRecordsExtraUsageAndSeparateLatency`；本分支复跑两次，一次 7/7 全过，一次失败同一个时延用例。全量运行时失败的麦克风用例在复跑中通过。

修正后 Spotless、Mapper XML 与 Prettier 格式检查、Maven Enforcer 依赖门禁均通过。GitHub CI 结果以 PR 检查为准。

## 未实现与边界

- P2 未实现：按有效线索结算与对账单、企业 API（API Key + HMAC）、IP 白名单、短信二次验证、数据保留期自动脱敏。
- 新线索的 Webhook / 短信推送未实现，企业端以未读数和计数卡片提示。
- 录音播放返回通话的 `recording_url`，是否可直接播放取决于部署的录音存储，未新增签名下载。
- 测试环境未发布、生产未发布；真实线路、录音存储与企业侧实际使用未验证。
