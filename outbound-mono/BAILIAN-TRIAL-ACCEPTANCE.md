# 百炼原生试聊与可选二次审核验收

日期：2026-10-27。基线：`027160b`（PR #97）；本次分支：`feat/bailian-native-comparison`。

本轮将默认链路改为百炼原生，将独立 ASR + 二次审核保留为显式选择的对照模式。用户尚无百炼账号，验收使用本机模拟供应商、MySQL 和 Chromium 假麦克风，不声称真实供应商闭环或真实设备验收通过。

## 页面、入口及状态清单

| 页面/入口 | 本轮验收要求 |
| --- | --- |
| 登录、独立百炼试聊菜单、语音方案入口 | 实际点击进入、页面内容完整、返回路径有效 |
| 百炼配置 | 填写、加密保存、刷新回显、密钥脱敏 |
| 创建试聊 | 默认原生；客户和话术可填；原生不依赖额外审核凭证；对照按需检查凭证 |
| 模式及单价 | 可选择、创建时冻结；活动会话不能切换；请求模式/单价改变时幂等冲突 |
| 原生会话 | 麦克风、文字、多轮、直接音频播放、供应商回复文字；不标注二次审核通过 |
| 二次审核会话 | 独立识别、短句审核、放行；风险阻止播放；不自动降级到原生 |
| 测量面板 | 套件/额外 ASR/二次审核分项，估算与实际账单区分；逐响应三段时延；未知不记零 |
| 历史与录音 | 原生/对照筛选、保存刷新回显；历史模式和价格不随新表单选择改变 |
| 业务结果 | 人工确认写入原有客户跟进、重复确认幂等、跳转及返回 |
| 异常及授权 | 匿名、非管理员、跨租户、一次性票据、退出、断开、旧响应隔离、缺配置、数据库异常 |
| 数据迁移 | V1–V23 空库、重复迁移零执行、V18 升级保持原通话预留；旧测量未知 |

原平台关键业务回归：登录 → 客户搜索/维护 → 话术 → 模拟任务 → 模拟通话/质检 → 报表 → 客户领取与跟进 → 返回 → 退出。仓库无商城页面，门店/房型/购物车/下单/支付链路不适用。

## 验证结果

本地完整执行包含 317 项单元测试和 328 项集成测试。首次完整执行中 317 项单元测试通过；集成测试 327 项通过，原有 `FrontendBrowserIT` 在个人配置保存后立即刷新，读取先于保存完成，出现一项失败。已将用例改为等待 POST 成功响应后刷新，保留保存回显断言，最终复验结果见下。

- 原生模式在模拟审核端返回风险时仍不发起额外 ASR/审核；接口计数验证额外调用为零。
- 对照模式确实调用独立 ASR 和内容安全，风险拦截后不播放，不降级为原生。
- 创建时固定模式和单价；更换参数重用请求标识返回 409。费用公式、空单价、零调用、缺失时延分别测试。
- 原生中途打断保留已放行录音，丢弃迟到音频及回复；浏览器/数据库异常仍关闭供应商连接。
- V1–V23 空库、重复迁移、V18 通话预留兼容、V22 旧试聊升级均通过。
- 最终复验 `bailian-native-final.log`：10 项专项单元测试、11 项集成测试（完整页面回归、数据库迁移、百炼试聊）全部通过，BUILD SUCCESS。完整执行加定向复验后的报告汇总为 **317 项单元 / 328 项集成，失败、错误及跳过均为零**。
- 浏览器检查共 **54 项**：原平台 35 项、原六套语音配置 10 项、百炼原生/对照 9 项，错误数组均为空。实际使用 Chromium 假麦克风，覆盖点击、表单、加密保存、刷新回显、结果写回、返回及退出/权限边界。
- 已查看百炼页面全页截图，模式、三项费用、逐响应时延和历史筛选显示完整。

构建已通过 Java 编译、前端构建、Spotless、Mapper XML 与 Prettier 检查。初次受限运行的 Mockito 自附加因沙箱失败；在允许隔离容器/JVM 测试的环境重跑通过，不属于应用缺陷。前端打包仍有既有 chunk 大小提示，无构建失败。

GitHub PR 检查和合并后 main 检查以远端记录为准；提交前本文件只记录已经取得的本地证据。

证据路径：`target/bailian-native-targeted.log`、`target/bailian-native-full.log`、`target/bailian-native-final.log`、`target/surefire-reports/`、`target/failsafe-reports/`、`target/bailian-browser-results.json`、`target/bailian-browser.png`、`target/frontend-browser-result.json`、`target/voice-ai-browser-result.json`。测试数据为模拟数据，不是费用或延时的真实基准。

## 已知限制与上线前置条件

- 无百炼账号：真实应用权限、模型音色、工具透传、供应商原生审核范围、扣费与断开后计费均未验证。
- 原生模式仅代表不经过平台额外审核，不代表“已通过独立安全审核”。原有六套电话组合的审核逻辑不变。
- 仍采用点击开始/结束说话、手动打断，单实例四路试聊；不代表自动双工或电话并发容量。
- 单价为手填估算，实际账单待对账；未知价格/缺失时延不按零处理。原生与对照的实测 P50/P95、效果及账单差异尚无结论。
- 浏览器回执不是声卡实际发声；真机、Safari/手机、目标部署环境和弱网长稳未验证。
- 录音每会话 12 MB，历史最多显示 100 条；自动保留期和删除任务未实现。异常退出只保留最后成功写入的测量快照。
- 正式联调先提供百炼账号、应用、API Key、公网 HTTPS 工具回调与业务资料；只有选二次审核时才需额外 ASR、内容安全 RAM 及地域。密钥使用平台加密配置或本地未提交密钥文件。
- 上线前须完成真实原生闭环、可选对照、账单和延时对齐、测试环境及真机验收；核对可信代理和数据保留配置。代码合并不会自动发布或开启外呼。
