## 集成与数据边界

- 不新增数据库迁移或改写历史迁移。配置、游标与回执复用现有持久表；通话节点记录使用现有事件账本。任务创建、拆分、分配和规则保存沿用版本校验及事务。
- 新接口、企微桥接与推送采用既有公网 HTTPS 校验与固定解析地址传输，不接受重定向或任意内网目标。接口与通知任务在写锁外执行，外部接收方应按交付编号去重。
- 推送 AES-256-GCM 使用随机12字节 nonce；HMAC-SHA256 签名覆盖 `timestamp + "." + body`，接收方检查时间窗口及交付编号。密钥不通过配置读取接口返回。
- 企微桥接 JSON 为 `phone / wecom_id / app_key / rule_id / version`，请求头含 `Idempotency-Key / X-Webhook-Timestamp / X-Webhook-Signature`。HTTP 2xx 只表示受理，好友通过数仍来自实际登记。未知竞品服务商协议不宣称字节兼容。
- 号码隐藏为不可撤销的任务展示策略；真实拨号仍需服务端保存号码。它不等同于删除原始导入数据。全局、任务、角色及导出范围共同约束读取。
- 噪声门为低幅 PCM 处理，不能当作已验证的复杂环境降噪。供应商只使用其已支持的参数；发音人、语调及词表效果需要真实供应商联调。
- 本次没有可用真实 SIP/RTP、云语音、短信或企微凭据。没有发起真实外呼、短信或加好友，也未部署生产环境。容量结论沿用原验收，功能回归不证明500 CPS或500路达标。
