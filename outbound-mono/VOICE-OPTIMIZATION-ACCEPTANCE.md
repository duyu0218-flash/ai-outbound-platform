## 配置及兼容

后台入口 `/admin/voice-ai`。新增配置随通话策略冻结，只作用于新通话：

- `input_turn_controller`：默认 observe；enforce 只开放三段式。供应商 final 到达前不提交业务，final 晚于本地端点时不再机械等待第二个静音窗口。
- `tts_prepare_parallel`：默认 true；仅并行连接准备，不允许未审核文本进入 TTS。
- `conversation_history_turns`：记录条数，一条客户发言或助手回答各算一条；`conversation_history_chars` 默认 6000。
- `customer_asr_options`：JSON，默认 `{}`。例：`{"aliyun":{"vocabulary_id":"vocabulary-id"},"volcengine":{"boosting_table_id":"corpus-id"},"tencent":{"hotword_list":"车型|5","word_info":1}}`。不允许未知字段、同时指定腾讯两种热词来源，或使用 11/100 的强制热词权重。
- `output_audit_asr_options`：独立 JSON，默认 `{}`。只允许受支持的审核模型及腾讯 word_info，不接受热词或过滤敏感词。例：`{"aliyun":{"asr_model":"fun-asr-realtime"}}` 同时将声明和实际重采样改为 16k；该型号与当前 8k 模型需分开做准确率/价格评测。
- `safety_fallback`：默认 approved_audio_then_end，也可选择 end。保存后显式准备音频；不会在审核失败时新发 TTS 请求合成兜底。
- 平台环境变量 `VOICE_AI_INGRESS_MAX_QUEUE_MS` 默认 4000，范围 100—4000。队列仍最多 4 帧、65536 字节，时长预算是附加上限。兼容现有大帧输入后再按实际包长调低；不得把 4 帧当成固定 80ms。500ms 预算有独立故障注入测试。

三段式新增独立云审核依赖；真实拨号前与 S2S 一样检查 `VOICE_AI_SAFETY_*`。缺少审核配置不允许生成音频绕过审核。凭据不进入配置快照、页面结果或 Git。

回调采用新增字段扩展文件 `contracts/voice-optimization-fields.json`，不改冻结的旧基线。`provider_final=true, turn_committed=false` 仅入原始证据，不能增加业务代际或执行 AI 话轮；旧回调的 final 语义保持兼容。recognition_quality 进入持久 outbox，缺帧输入先澄清，原始字段不被伪造或静默修正。

## 测试与状态

最终命令与计数见 `voice-optimization-validation.json`；本地日志位于忽略目录 `verification/voice-optimization-20261026/`。构建使用 Java 21 / Maven 3.9.11、冻结前端依赖、独立 MySQL 8.4/Redis 测试容器及 Chromium。

全量回归与修复后的定向复测合并覆盖 307 项单元、320 项集成测试，当前报告失败/错误/跳过均为 0。最终源码末次 `verify` 执行 81 项语音单元及 VoiceAiHttpIT / FrontendBrowserIT，构建通过；主业务浏览器 35 组、语音页 10 组检查通过。初轮发现的大帧预算兼容和页面切换等待问题已纳入回归；保存路径明确检查选择值、HTTP 请求、服务端返回与刷新回显。Spotless、Mapper XML、前端格式、依赖 Enforcer、独立 Jar 启动和测量工具合成自检通过。合并计数不是声称末次单次运行了 627 项；远端完整 CI 以 PR 检查为准。

```sh
cd outbound-mono
mvn -B verify
mvn -B enforcer:enforce
node ../tools/test-voice-measure.mjs
```

测试重点：TTS 握手未完成时 LLM 已启动；未审/取消后文本零提交；第二句风险不放行；S2S 只播已准备兜底并保持原错误；多个 final 聚合及去重；final 晚到不重复静音等待；完整数字/拒绝短答不因包含关键字而一律长等；有缺口的早段不能被干净后段覆盖；8k/16k 模型参数和实际重采样一致；PCM 前缀释放后绝对边界保持有效；HTTP 合约不丢失质量与审核证据。

## 已知限制和上线前置条件

真实时延收益、CER/关键意图准确率、账号参数接受情况、审核覆盖/误拦截、线路和端侧回执均未验证。本地成功不证明真实供应商或生产容量通过。

尚未实现或启用：Silero/Smart Turn、AEC/降噪、自适应供应商网络包聚合、结构化异步摘要、final/partial 预生成、部分播放片段账本、S2S 取消后原会话复用、模式 B 文本先审、本地 Guard/ASR、跨节点中央额度。不能将现有能力标为这些项目已经完成。

上线前必须取得已授权的真实录音/标注、受控号码与测试凭据，完成真实供应商协议验证、电话端时延/准确性、审核对抗集、插话/告知/兜底回执、逐级容量与长稳、业务/成本试点和回退演练。转人工仍由原业务状态机执行，未验证的坐席承接不得表述为转接成功。默认路由及高风险实验不得因本次代码更新自动开启。
