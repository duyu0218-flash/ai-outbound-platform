## 页面与状态覆盖

每个受影响入口验证点击、正确页面、内容、表单、保存回显、返回路径、登录/退出和异常。关键业务回归为：登录 → 名单 → 话术/知识 → 外呼任务 → 模拟通话 → 质检 → 线索交付与跟进 → 报表/用量 → 退出；另外验证短信和跨渠道营销链路。系统无门店、房型、购物车、支付入口，商城链路不适用。

## 发布边界

111 仅更新已存在的隔离测试应用，保留 mock、外联隔离、DAS/调度/worker 关闭等现有保护。真实拨号、短信、模型/语音供应商收费操作未获本次逐次计费授权，不执行。发布前核对当前服务、活动任务、版本和备份，部署失败恢复旧版本并保留迁移审计。

## 最终报告要求

分别报告源码、静态检查、开发环境功能测试、测试发布、真机、生产发布六项状态，以及已验证、未验证、已知问题、环境限制和正式上线条件。没有证据的内容标为未验证。

## 本地验证记录

2026-11-03：全量功能轮次 347 项单元测试、433 项集成测试通过；该轮格式阶段因同时修改源文件而未通过，未记为完整构建通过。随后冻结源码，ResourceLayoutTest 与 21 项 CustomerHttpIT 的 verify 完整通过，FrontendBrowserIT 的 verify 完整通过（47 组浏览器检查），Java/资源/前端格式检查通过；依赖策略、语音零费用契约和消息 API 客户端检查通过。营销、语音配置、百炼界面的专项浏览器回归分别通过 7、10、9 组。最终合并条件仍为 PR 同一提交全部应执行 CI 通过。

名单覆盖 XLSX、字段映射、预览、错误下载、重复处理、跨分块幂等、导入中断恢复和失败重试。任务覆盖发布版本冻结、租户隔离、转人工团队校验、未来起始时间及结束边界。测试为隔离数据库及模拟供应商，不构成真实拨号、真实短信、供应商计费、真机或容量验收。
