# 2026-09-04 代码审查修复与验收

## 变更范围

修复账号切换缓存隔离、短信误置通话终态、回调入队事务、迟到 AI 结果、外部模型转人工分支、迟到座席未接听事件六项问题。
账号隔离通过每个登录会话独立的 QueryClient 实现，覆盖普通查询、直接 useQuery 和 mutation 缓存，不改变已有缓存失效键的语义。
Webhook 使用函数作用域事务：业务服务内 commit 仅释放保存点，整条回调和 outbox 一起提交，提交完成后才运行后台任务。

本项目是外呼平台，不含“门店/房型→购物车→下单→支付”业务链；该电商链路不适用。
外呼回归采用“登录→联系人→话术/活动→通话→转人工/短信→记录→退出”，分别标注浏览器与模拟接口证据。

新增后端回归包含四类 webhook 的失败回滚、重复重试、后台任务只能读取已提交数据，以及模型/播放/短信等待期间挂断和新拨号轮次的过期结果丢弃。AI 异常及任务重试耗尽不会作为 PBX 已挂断的证据，不释放未确认结束的通话容量。

浏览器跨租户用例使用明确种子的合成租户：默认演示管理员的联系人名 SyntheticTenantA；第二租户管理员 review-b 的联系人名 SyntheticTenantB。仅在独立测试库准备好这些数据后设置 E2E_REVIEW_TENANTS=1，默认 CI 不设该变量会跳过此用例。不得向生产库创建这些测试账号。

## 未验证项、限制与上线前置条件

- 本轮没有验证真实 SIP、运营商、云 ASR/TTS、短信供应商及手机端；模拟接口成功不等于真实商用验收。
- 没有进行生产数据迁移、真实线路容量压测或长时间故障恢复演练。
- 浏览器验证覆盖上述入口和状态，不代表全系统所有表单、所有角色或所有异常组合都已验收；外呼策略链通过后端模拟回归验证，不是浏览器实拨。
- 未发现上述六项在已覆盖场景中仍可复现的问题。修复前已丢失的历史任务不自动补发，避免造成意外拨号、短信或重复回调；若有历史异常记录需单独授权审计与恢复。
- 正式上线前需要部署评审、目标环境配置复核、真实线路/云语音/短信验收、容量和故障恢复演练。本地提交不代表推送、CI、合入或发布。
