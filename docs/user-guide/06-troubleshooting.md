# 常见问题

[返回目录](README.md) · [验证记录](VALIDATION.md)

| 遇到的问题 | 先检查什么 | 后续处理 |
| --- | --- | --- |
| 登录失败 | 登录入口、用户名、密码、账号启用和锁定状态 | 保留提示，联系管理员核对或重置；不要反复猜密码 |
| 登录后进错界面 | 使用的是管理员还是坐席入口，当前账号角色 | 退出后使用正确入口；普通坐席访问管理页会返回坐席端 |
| 任务无法保存 | 必填项、已选客户、并发范围、模板与发布版本 | 修正提示字段，再保存并回列表核对 |
| 任务启动失败或未继续拨号 | 同意与禁打状态、时间策略、容量、线路、任务状态 | 查看任务运营详情和事件，交给管理员检查依赖与调度 |
| 看不到客户或话单 | 时间条件、查询条件、负责人、团队和权限 | 先重置查询，再检查是否分配给当前坐席 |
| 没有导出按钮或提示无权限 | 当前用户的导出权限 | 管理员在“团队与权限”核对，不通过切换地址绕过限制 |
| 号码被脱敏 | 是否获准显示完整号码 | 联系管理员核对操作权限 |
| 录音为空或不可访问 | 是否结束、录音开关、资产状态与权限 | 技术人员核对存储和处理任务；资产记录不等于音频完整可播放 |
| 话术画布不能保存 | 是否正在查看已发布版本 | 在新的草稿或版本中修改，发布后供新任务选择 |
| 重拨按钮禁用 | 会话是否结束，尝试次数是否耗尽 | 查看尝试次数和事件，避免重复发起 |
| 跟进或配置提示版本冲突 | 是否有人同时修改 | 刷新读取最新值，核对后再提交 |
| 个人配置无法编辑 | 是否使用团队统一配置 | 管理员在团队设置中调整或允许个人覆盖 |
| 软电话提示未启用 WebRTC | 服务器 WebRTC、坐席配置及设备 | 联系管理员；本轮截图环境属于此状态 |
| 右上角显示在线但无法打电话 | 应用探测与电话链路是不同检查 | 分别检查线路、注册、设备、媒体和外部服务 |
| 报表数字不一致 | 时间、范围、分组、状态、去重口径 | 从报表下钻到话单核对，跨组唯一号码不要相加 |
| 费用与服务商账单不一致 | 页面为按秒折算的估算费用 | 按服务商结算口径对账 |

## 向管理员反馈时提供什么

提供发生时间、当前页面、账号角色、任务或会话编号、操作步骤、错误提示，以及脱敏后的截图。不要在公开 GitHub Issue 中粘贴密码、令牌、完整客户名单或真实录音地址。

## 本轮已知限制

- 本地测试使用 Mock 通话与临时数据库，未启用真实 WebRTC。
- 浏览器回归日志中出现未启用媒体接口的 403，以及错误密码测试预期的 401；页面展示了对应状态，不能据此宣称真实语音链路通过。
- 录音截图显示资产信息，真实录音播放、下载、存储可达性和音质未验证。
- 前端构建有主包体积提示，未在本次文档任务中调整业务代码。
- 任务暂停／恢复／停止、删除、真实短信和第三方回调的本轮实际验证范围见验证记录。

上线前的技术要求以[部署文档](../../outbound-mono/DEPLOYMENT.md)为准；本手册用于操作说明。
