## 一次外呼工作的顺序

1. 管理员准备账号、团队和已验收的线路，核对系统配置。
2. 在“客户管理”新增客户，或在“客户运营”导入 CSV，核对同意状态与禁打状态。
3. 在“话术管理”准备话术；需要流程编排时创建、保存并发布话术画布。
4. 在“外呼任务”选择客户、外呼模式及话术，保存后核对列表，再确认启动。
5. 在“通话记录”与“话单查询”观察结果，打开转写、质检、录音和事件证据。
6. 在“线索与跟进”分配负责人、记录结果、安排下一次跟进。
7. 在“运营分析”查看同一统计范围的结果，按权限导出并核对口径。

## 入口与账号

平台地址由部署管理员提供，以下路径接在平台域名后面使用：

| 使用人 | 登录路径 | 登录后的主要工作 |
| --- | --- | --- |
| 管理员 | `/admin/login` | 配置、任务、运营与租户内管理 |
| 坐席 | `/agent/login` | 接待、本人话单、线索跟进与个人配置 |
| 主管坐席 | `/agent/login` | 坐席工作与授权范围内的质检 |

使用管理员实际开通的账号。截图中的 `browser-*` 是隔离测试账号，线上不能据此登录。平台没有公开注册入口。

本轮没有变更业务功能。各页面与状态的验证范围见[验证记录](VALIDATION.md)，真实线路、设备和生产环境状态单独列明。
