# 管理配置

[返回目录](README.md) · [下一章：坐席操作](05-agent.md)

管理员在上线或调整业务前核对本章配置。各页保存的是平台设置，真实线路、模型、短信和回调能否工作，仍需对应服务验收。

## 1. 账号与坐席

入口：管理员 → 用户与座席，路径 `/admin/users`。

![用户列表](images/users.png)

![新增用户表单](images/user-form.png)

1. 点击“新增用户”，填写用户名、姓名和密码，选择管理员或坐席角色，按需设置主管标志与启用状态。
2. 密码按页面校验要求填写；当前表单至少 8 位。
3. 保存后在列表核对账号。需要调整时进入编辑，用户名不可修改。
4. 编辑密码字段留空表示不重置；需要重置时填新密码并保存。
5. 账号被锁定时，管理员核实原因后使用出现的“解锁”入口。

新账号创建不等于团队与数据范围已经配置完成，继续核对团队成员和操作权限。

## 2. 团队、技能和操作权限

入口：管理员 → 团队与权限，路径 `/admin/operations/teams`。

![团队与操作权限](images/teams.png)

1. 点击“新增坐席组”，填写组名、启用状态，选择成员。
2. 按需要勾选成员的“组长”标志。
3. 输入接待技能，例如业务、地区、语言，设置通话后整理秒数、转接等待秒数。
4. 决定是否允许个人覆盖团队配置，点击“保存坐席组”。
5. 重新打开“编辑坐席组”，确认成员、技能和时间设置回显。

![坐席组表单](images/team-form.png)

在“用户操作权限”选择用户，核对“允许导出”“显示完整号码”“访问录音”，点击“保存操作权限”。普通坐席默认关闭导出并使用脱敏号码；管理员保留租户内管理权限。组长和主管的可见范围以实际授权为准。

## 3. 外呼线路

入口：管理员 → 外呼线路，路径 `/admin/lines`。

![线路列表](images/lines.png)

![新增线路表单](images/line-form.png)

1. 点击“新增线路”，填写名称、服务商、网关地址、凭证引用、主叫号、并发、优先级、权重及启用状态。
2. 凭证引用填写管理员配置的引用名称，不将真实密码或服务密钥写入名称等普通字段。
3. 保存后核对列表与启用状态，必要时使用行内开关停用线路。
4. `Mock` 仅供测试；正式使用须由技术人员验收真实网关、路由、主叫号、并发和媒体链路。

本轮验证了 Mock 线路保存、回显和停用，没有验证真实运营商线路。

## 4. 系统配置

入口：管理员 → 系统配置，路径 `/admin/settings`。切换标签后填写，使用当前标签内的“保存”按钮。

### 并发容量

![并发容量配置](images/settings-capacity.png)

核对租户同时通话上限等容量参数。配置值不代表已经完成容量验收；任务并发受到有效容量约束。

### AI 与语音

![AI 与语音配置](images/settings-ai.png)

核对模型名称、已接入的 AI 与语音设置。保存后重新进入该标签确认回显；云端模型、ASR、TTS 和音频效果需要专项验证。

### 短信配置

![短信配置](images/settings-sms.png)

填写已申请的签名与服务配置，保存后核对。挂机短信开关开启后是否真正发送，需对照短信记录与服务商结果。

### 合规策略

![合规策略](images/settings-compliance.png)

根据实际业务核对时区、可呼叫时段及联系策略。任务未发出时，先检查此处和客户授权、禁打状态。

### 接口与回调

![接口与回调](images/settings-integration.png)

核对回调地址、超时与页面列出的集成配置，保存后确认。地址可保存不代表外部系统可达或已经签收数据。

## 5. 业务交付策略

入口：管理员 → 业务交付策略，路径 `/admin/product`。先确认当前策略适用范围，再编辑、试跑和发布。

![对话与异常处理](images/product.png)

“对话与异常处理”设置沉默等待、澄清、模型等待提示、打断和异常结束语。按真实业务话术填写，不靠增加等待时长掩盖服务异常。

![信息采集](images/product-slots.png)

“信息采集”维护需要获取的信息及确认方式，核对必填要求。

![转人工与时间安排](images/product-handoff.png)

“转人工与时间安排”选择可接待团队、技能、等待限制和预计转人工比例等参数。团队、坐席状态与承接能力应一起核对。

![试跑与版本](images/product-test.png)

在“试跑与版本”运行对话试跑，核对结果后点击“发布策略”。页面提示“策略已发布，下次通话生效”后，重新进入核对版本与字段。试跑属于本地策略验证，不代表真实语音已经通过验收。

![预约回拨](images/product-callback.png)

在“预约回拨”查看预约处理情况；按实际要求处理后续联系。

![人工跟进](images/product-work.png)

在“人工跟进”查看需要人员处理的事项。

![交付统计](images/product-statistics.png)

在“交付统计”核对结果分布与口径。

![交付结果](images/product-results.png)

在“交付结果”查看单条结果、摘要与采集信息，必要时回查对应通话。

![知识导入与检索测试](images/product-knowledge.png)

“知识导入与检索测试”支持填写标题、出处、正文或导入文本文件。点击“保存知识”后输入检索问题，点击“测试检索”，核对匹配内容。截图采集时检索输入与临时结果未保留；本轮浏览器回归另行验证了保存与检索。

## 6. 表单模板、标签字典与业务连接

入口：管理员 → 表单标签与连接，路径 `/admin/operations/configs`。

![表单模板](images/config-forms.png)

点击“新增表单模板”，填写名称和字段，点击“发布表单模板”。修改已有模板使用“基于此版编辑”发布新版本；在线索人工补录中选择对应版本。

![标签字典](images/config-tags.png)

在“标签字典”输入标签名称，选择客户或通话对象，点击“发布标签”。为对象选择标签后，还需点击对应的“保存对象标签”；发布字典不等于已经给客户打上标签。

![业务连接](images/config-connections.png)

在“业务连接”核对回调超时等配置并保存。真实第三方回调和签收结果未在本轮验证。

## 7. 通知中心与个人配置

![管理员通知中心](images/notices.png)

通知中心入口 `/admin/operations/notices`。点击“刷新通知”获取列表，点击“查看事项”标记已读并进入对应线索或话单。

![管理员个人配置](images/admin-workspace.png)

坐席个人配置入口 `/admin/operations/workspace`。允许个人配置时可调整整理秒数和人工接收等待秒数，点击“保存个人配置”后刷新确认。显示“使用团队统一配置”且输入禁用时，由管理员在团队配置中调整。

## 8. 监控与审计

入口：管理员 → 监控与审计，路径 `/admin/system`。

![监控、审计与短信记录](images/system.png)

查看服务健康、容量、任务积压、审计日志和短信记录。排查问题时记录发生时间、任务或会话编号、错误提示及相关审计动作，再交给技术人员。

健康探测成功不能替代真实语音、录音存储、外部模型和容量验收。
