## 本轮已验证项

- 客户：必填提示、创建、编辑、搜索、保存后刷新；CSV 导入、导出与批量禁打。
- 话术与任务：创建话术、拖动画布、保存、发布只读；客户选择、创建任务与启动。
- 通话：完成态模拟会话证据标签；有剩余次数的模拟记录重拨后递增次数，刷新保留。
- 运营：话单组合筛选、空结果、URL 与常用视图回显、导出、详情返回；线索分配、跟进、补录、标签、历史与刷新。
- 配置：用户创建、Mock 线路保存与停用、知识新增、系统五分区保存、团队及权限、表单版本、标签、个人配置。
- 策略与分析：人工承接参数持久化、试跑与发布、知识保存和检索；报表生成、导出、保存视图、下钻与返回。
- 会话与权限：管理员／坐席／主管登录、退出、错误密码、保护页面、坐席状态服务端回显、数据范围与管理入口隔离。
- 图片：63 张截图已按缩略图总览逐张检查，异步表单和抽屉重拍并放大复核；空状态按实际展示保留。

业务链路复验：管理员登录 → 客户创建／搜索 → 话术发布 → 任务创建／启动 → 模拟通话证据 → 话单查询／导出 → 线索分配／跟进／补录 → 报表下钻 → 坐席状态与权限 → 退出。

项目没有门店、房型、购物车、下单、支付或“我的”商城链路，这些检查在本项目中不适用。

## 未验证项

- 任务暂停、恢复、停止、删除等操作的本轮实际点击验证；用户密码重置、停用和解锁。
- 真实 FreeSWITCH、SIP、RTP、运营商线路和真实号码拨打；人工队列接受／拒绝及桥接音频。
- 真实 WebRTC、麦克风、耳机、浏览器权限与真机接听。
- 云端 ASR、LLM、TTS 效果和延迟，短信实际送达及第三方回调签收。
- 真实录音播放、下载、对象存储可达性、音质与完整性。
- 生产数据与统计对账、服务商计费、生产备份恢复、目标 Linux、长稳和容量验收；本轮没有验证 500 CPS。
- 当前演示坐席无分配线索，已验证其入口和空状态，没有在该账号下验证全部跟进写入。

## 已知问题与环境限制

- 本地使用 Mock 电话与隔离临时 MySQL，WebRTC 未启用。通话完成和重拨均为模拟路径。
- 未启用的坐席媒体接口在浏览器日志中出现 403；错误密码测试产生预期 401。两者不计为页面脚本异常，也不等于真实语音验收通过。
- 部分转写、录音、阶段指标、主管待复核、交付数据为空。手册展示的是入口与空状态，没有补造真实业务数据。
- 前端构建成功，有主包超过建议体积的提示；本次未处理该性能事项。
- 全页截图可能需要点击放大，左侧长导航需滚动；不同浏览器的日期控件和时间显示形式可能不同，操作时核对时区。

1. 按[部署文档](../../outbound-mono/DEPLOYMENT.md)准备目标环境、配置与凭证，执行备份和恢复演练。
2. 核对客户授权、禁打、呼叫时段、账号与团队数据范围；用受控测试号码完成真实线路和转人工闭环。
3. 验证设备、录音、外部模型、短信与回调，核对实际音频和业务结果。
4. 完成目标宿主的容量、长稳、计费对账与发布验收。当前单体仅支持单实例，升级前停止旧进程，禁止重叠和滚动升级。
5. 将目标环境、真机和生产的实际结果分别记录，再完成对应发布。

## 复验命令

本轮使用已安装依赖，先构建，再运行指定浏览器集成测试：

```sh
cd outbound-mono
mvn -B -DskipTests package
MONO_CAPTURE_MANUAL=true mvn -B -Dit.test=FrontendBrowserIT failsafe:integration-test failsafe:verify
```

从仓库根目录运行：

```sh
node outbound-mono/frontend/tests/manual-validate.mjs
node --check outbound-mono/frontend/tests/manual-capture.mjs
node --check outbound-mono/frontend/tests/manual-validate.mjs
git diff --check
```

Maven 使用本机预装的 JDK 21、Maven 3.9.11 和离线依赖缓存；浏览器为 Playwright Chromium。本轮仅运行与文档对应的浏览器集成回归，没有重跑全部后端单元与集成测试。
