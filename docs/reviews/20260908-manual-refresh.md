## 已知问题与环境限制

1. 业务策略和合规设置各有时间门槛。只调整合规时段仍可能等待业务服务时间；手册已补充两者都须检查。排队显示的细粒度原因仍不足，需结合后台队列定位。
2. `waiting_human`、HTTP200、`result=received`、配置保存和容器就绪分别只代表对应状态，不代表客户接通/人工接通/消息送达。
3. 单服务器500总在途仍未商用验收，最新回调持续吞吐/队列SLO失败边界保留在[Inbox报告](20260908-callback-inbox.md)。本次不重跑容量压测。
4. 未访问运营商、云ASR/TTS/LLM、短信、正式域名/证书/TURN控制台；这些第三方操作截图待补。安装工具与命令步骤以可复制命令和真实输出交付，不伪造终端或云控制台截图。
5. 本次未重跑全部后端/语音/媒体容量测试；相关已有提交的历史报告是历史证据，远端CI状态应单独读取。
6. 长任务表单最初在1050px视窗中底部不可见；改用1800px视窗重新截图完整对话框，不修改页面源码或原始数据。
