# 导出文件与企微请求历史修复

异步导出不再把新文件写入 `ops_export_job.content`。表内保留归属、筛选条件、文件引用、字节数、权限快照和有效期；CSV 按页写入临时文件，自定义 ZIP 的各成员逐条落盘。生成过程限制 UTF-8 实际字节数，普通文件和 ZIP 压缩内容不超过 12 MiB，ZIP 解压内容合计也不超过 12 MiB。下载仍经过原用户、租户、当前权限和话单可见性检查，再以流返回文件。

## 配置与迁移

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `EXPORT_STORAGE_MODE` | 生产 `s3`，其他环境 `local` | 对象存储或私有本地文件目录 |
| `EXPORT_STORAGE_DIR` | 本地模式 `data/exports`；S3 模式系统临时目录下 `outbound-export-spool` | 本地模式为持久目录；S3 模式仅作临时生成目录 |
| `EXPORT_RETENTION_HOURS` | 168 | 下载有效期，允许 1 至 2160 小时 |

S3 模式复用 `S3Store` 和录音角色的配置映射，包括 `S3_ENDPOINT_URL`、`RECORDING_S3_BUCKET` / `S3_BUCKET`、`RECORDING_S3_ACCESS_KEY_ID` / `S3_ACCESS_KEY_ID`、`RECORDING_S3_SECRET_ACCESS_KEY` / `S3_SECRET_ACCESS_KEY` 及对应 `_FILE`。导出对象使用独立的 `exports/{tenant}/{job-id}` 前缀，部署账号需要对该前缀有上传、读取和删除权限。不得将此目录或前缀设为公开访问；应用不返回对象直链。

生产采用本地模式时必须明确设置持久 `EXPORT_STORAGE_DIR`，挂载给运行 UID 并随应用数据一起备份。S3 模式只需为临时目录预留空间，文件发布后即可删除本地临时内容。本次没有调用真实 S3 服务，实际服务权限和生命周期须在部署环境验证。

V49 为导出表增加引用、字节数、有效期以及队列/过期索引，并为业务文档增加租户、类型、更新时间和 ID 的分页索引。既有 BLOB 保留兼容下载，并自迁移时起获得七天保留期；无需一次性搬迁旧文件。旧文件权限校验保持生效。回滚应用时，旧版本不能下载新外置文件；应先排空导出队列并保留新版本下载服务至文件过期，或同时恢复数据库与文件备份，不能只回退 Jar。

## 队列与恢复约束

- 每个用户最多五个排队或处理中的请求，每租户最多二十个。租户行锁将额度判断和插入放在同一事务中，避免并发越限；相同幂等键重试仍返回原任务。
- 工作线程按租户 ID 循环选择一个任务，同租户内按创建时间和 ID 排序。每轮最多处理四个任务，并沿用调度时间预算，防止单租户连续提交占满队列。
- 领取时先记录对象键，再生成和上传文件。上传后数据库提交失败时尝试删除对象；删除失败保留键并进入到期清理重试。进程在上传后崩溃，旧 `processing` 任务恢复后继续使用相同对象键生成和覆盖，不产生新的对象名。
- 文件到期立即拒绝下载，清理是否完成不影响这一判断。每轮最多处理 25 个到期文件；外部删除失败不丢失文件引用，设置独立的五分钟重试时间并排在尚未尝试的过期文件之后，下载有效期不延长。超过两小时的未发布本地临时片段会分批清理。
- 权限快照在生成前保存，生成后再次核对；下载时仍核对当前权限。生成或上传期间发生权限变更，不会用新权限替旧内容背书。

## 企微历史接口

控制台使用 `/api/v1/ops/wecom/requests?page=1&size=20`，响应包含 `rows`、`total`、`page`、`size`，支持 `state` 和 `request_id` 筛选；单页最多 200 条。按更新时间降序、ID 升序稳定排序。前端提供总数、页码、跳页、每页数量及请求状态筛选，旧请求不受最近 1000 条配置列表上限影响。

无参数的旧接口仍返回数组以兼容已有调用，同时返回 `X-Total-Count`、`X-Result-Truncated` 和分页入口 `Link`，避免调用方误认为截断结果就是全部记录。两种响应均要求管理员权限，并按当前租户过滤。

## 验证范围

专用回归为 `ExportStorageTest` 与 `ExportHistoryIT`：累计字节限制、本地重启持久性、非法路径、临时残留清理、1005 条历史首尾分页及租户隔离、并发队列额度、跨租户轮转、外置文件下载、权限变化、旧 BLOB 兼容、到期立即拒绝、整页对象删除失败后的续扫、上传后数据库提交失败及删除补偿重试、内容回收。原 `OperationsHttpIT` 继续覆盖自定义 ZIP、对话隐藏及下载权限变化。真实对象存储、生产备份恢复和高容量下载仍需目标环境验收。
