基线：`b72dbc8bd3feee9e2702974a250a3084c8fca88c`。本次处理功能与并发复审中的 R2–R10，并把 AI 外呼入口归并到同一侧边栏分组。R1 的百炼试听异步等待问题已由基线修复，本次保留原验收。

| 项目 | 最终行为 | 关键验证 |

| R3 集成队列 | 业务接口、分配、推送、回调、录音、短信使用独立有界执行器；同租户同聚合且同类别仍按序 | 慢推送隔离、节点过期、同键顺序、录音先写后删 |

| R10 消息队列 | 准备、恢复、查询、发送分离；租户/通道分区轮转，同通道有界并发；回收过期 CMPP 连接 | 查询不阻塞发送、慢通道隔离、行锁只领取一次、UNKNOWN 不重发、协议回归 |

## 页面、入口和状态清单

| 页面或入口 | 需要覆盖的状态 |
|---|---|
| 管理端侧边栏及原有全部可见入口 | 展开/折叠、活动路由、内容加载、直接 URL、刷新、角色权限 |
| 外呼任务创建/编辑、当前任务、历史任务 | 填写、预览、拆分、只创建、确认外呼、幂等重试、保存回显、取消返回、异常回滚 |
| 任务设置/智能评估、监控与统计 | 规则保存/刷新、多次尝试的指标口径、空数据、分页 |
| 话单查询/自定义导出、通知中心下载 | 查询条件、提交导出、排队/处理/成功/失败/过期、下载、权限变化、返回原查询 |
| 企微添加/企微配置/请求历史 | 配置保存回显、分页、页大小、状态筛选、空结果、刷新 |
| 登录、退出、管理员/主管/坐席会话 | 正常登录、错误密码、退出后拒绝访问、角色切换、过期会话 |
| 短信任务、业务接口、推送、录音 | 本地模拟提交、回执、超时、幂等、隔离、异常恢复 |

本项目关键链路为：登录 → 名单导入 → 话术/知识发布 → 创建外呼任务 → 显式启动 → 模拟通话与回执 → 话单/统计 → 跟进/企微 → 导出 → 退出。仓库不是电商项目，首页至购物车/支付链路不适用。

本地环境为 macOS ARM64、JDK 21、Maven 3.9.11、Node 24.19.0，数据库采用临时 MySQL 8.4/Redis 容器。名单耗时为该主机的单轮实测，不作为生产 SLA。测试使用本地协议模拟器，未调用实际付费线路、短信、企微或模型。

主要命令为 `mvn -B verify`；修复后的针对性复验覆盖 `DataLayerIT,DataLayerReplayIT,TaskStatisticsIT,QueueConcurrencyIT,TaskCreationScaleIT,ExportHistoryIT,FrontendBrowserIT,FatJarSmokeIT`，名单复验参数为 `-Dtask.scale.sizes=10000,50000,200000`。最后单独完成 `FrontendBrowserIT` 全链路及格式检查。GitHub 对本 PR 的最终提交再执行完整 CI。

## 部署和回滚前置条件

1. V47 含历史回填与同步事务触发器，必须先停止旧版本写入再迁移；在生产规模副本上测量回填时间和锁等待，确定维护窗口。迁移账户需具备创建过程和触发器权限。不要让旧实例在回填期间继续写入。
2. V48 增加集成队列分类、余额扫描游标及消息分区索引。保留原配额、状态条件及未知状态不重发规则；按供应商 TPS 配置线程数。
3. V49 为导出新增私有对象键和生命周期字段。生产默认 S3；本地模式必须挂载持久共享目录。对象存储、旧 BLOB 七天宽限和回滚约束见 [导出存储说明](20261106-export-storage.md)。
4. 数据库升级前备份并演练恢复；应用回退应保留新增表和字段，不能直接删除增量事实或导出对象。未做实际生产恢复演练。
5. 真实线路音频、真实设备、长时间运行及供应商限流仍需单独验收。500 个真实音频并发与 500 CPS 是不同容量目标，本次功能回归不构成生产容量认证。
