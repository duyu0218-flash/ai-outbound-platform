# 第一阶段语音修复与离线评测更新

基于本地 `e244773`，范围为现有实时语音链路可在本地验证的边界问题，以及离线转写对比工具。未接入 VibeVoice 推理服务，未改变业务实例的语音供应商或运行配置。

## 已修复与新增

| 问题 | 修复及证据 |
| --- | --- |
| 阿里云 NLS 空 SentenceEnd 被忽略，讲话状态不能结束 | 空识别也发送 UserStoppedSpeakingFrame；不伪造最终文本或触发 AI 话轮。新增复现测试修复前失败、修复后通过。 |
| 网关收到讲话结束帧后仍保留 barge_in 标记 | TranscriptWebhookProcessor 显式清除讲话状态并继续传递结束帧。新增复现测试修复前失败、修复后通过。 |
| StopTranscription 发送异常跳过父类清理，发送卡住也没有停止时限 | 发送和完成确认共用有界超时，finally 始终执行父类清理；保留任务取消语义，日志不拼接连接异常中的潜在凭据。覆盖断连、发送卡住和任务取消。 |
| 验收脚本把排队/转接原因当作人工已接通 | 两种转人工模式必须有 human_connected/in_human 状态；只有 waiting_human 或 handoff_reason 不通过。 |
| 人工优先模式在客户开口前转接，被脚本误判 ASR 缺失 | mixed_human_first 不强制客户 final；ai_only 保留至少三句、ai_handoff 至少一句要求。 |
| 非对象事件 JSON 导致验收脚本异常退出 | null/list 等载荷不进入状态提取。上述三项验收工具问题均有修复前失败的测试。 |
| 自动 API 验收容易被理解为完整线路通过 | 控制台改为 AUTO_PASS/AUTO_FAIL；报告注明 api_events_only，真实线路状态为 null，列出必须另行验证的声音与真机事项。 |
| 缺少冻结样本和跨模型对比工具 | 新增 scripts/evaluate_asr.py；检查授权/人工复核声明、清单与音频摘要、模型版本、重复/未知/缺失样本，计算加权 CER、目标词召回、角色文本 CER、离线耗时及费用，拒绝覆盖输入和既有报告。 |
| E2E 文件共享账号并发运行时互相撤销登录 | Playwright 默认单 worker；保留退出时撤销令牌的产品行为。 |
| E2E 登录跳转后立即计数，菜单尚未完成渲染 | 使用可等待的 toHaveCount(15)，保留全部 15 个入口断言。 |

离线工具使用说明见 [offline-asr-evaluation.md](../offline-asr-evaluation.md)。工具测试已加入 CI 配置，但远端 CI 本次未执行。

- 后端 SQLite：113 passed，2 skipped；跳过 PostgreSQL 专属测试。本次未改数据库模型，未重跑 PostgreSQL/Redis 集成环境。
- Voice Gateway：受控 Pipecat `1.8.1+outbound.1` 环境全量 **190 passed**，包含停止发送卡住与取消。最终输出保存在 `artifacts/phase1-20260906/gateway-tests.log`。

- 前端单元测试：8 passed；TypeScript 检查和 Vite 构建通过，产物输出到临时目录。
- Chromium：10 passed，19.6 秒；页面表单、保存回显和模拟业务状态链实际运行。任务编辑截图已检查，显示两个已保存客户。
- Python AST：语音网关源码和两个工具共 13 个文件通过；Git 差异检查通过。
- 离线 CLI：用明确标为 synthetic 的两组夹具实际运行，得到预期 CER 0 和 0.2，并保存比较报告。这是工具验证，不能当作云 ASR 或 VibeVoice 的效果数据。

隔离后端服务绑定 127.0.0.1:18966，使用新建 SQLite 库、关闭调度、mock 电话/短信，没有修改 8000 端口现有业务实例。源码从当前工作区导入，前端从本轮构建目录提供。

首次全量语音测试误用了历史 `.venv-voice-gateway`，触发旧依赖和沙箱端口错误；改用经 wheel 摘要验证的 `.venv-no-nltk` 后，发现仓库根目录 `.env` 仍会覆盖测试默认配置。最终在不读取该文件的临时目录复跑，保留本机配置。浏览器首次和第二次失败分别暴露上述共享账号与菜单等待问题，修复后全量通过，没有放宽断言或跳过场景。

## 已知问题、限制和上线前置条件

- 上述已覆盖缺陷未再复现；不代表全系统不存在其他缺陷。
- 当前离线工具接收统一 JSON 导出文件，尚无 VibeVoice 推理部署、原生输出转换适配器或业务质检页面回写；本轮不是模型接入完成。用户须在候选服务推理后按文件契约导出。
- 缺少本轮授权的真实中文电话样本、人工标准答案、候选推理硬件/服务和实测账单，无法给出模型准确率、费用优劣或并发结论。
- ASR 归一化不做中文数字语义转换；角色文本 CER 不是 DER；热词指标按每样本词是否出现计算，不是逐次词频命中。需按业务口径评审后再使用。
- 正式上线仍需完成测试环境发布、真实 SIP/PBX/ASR/TTS、双向声音、打断、转人工桥接、录音回听、故障恢复、目标并发长稳及真机验收，另行安排生产发布。

原文件和现有业务数据保留；合成测试报告位于忽略版本控制的 artifacts 目录。没有真实拨号、发送短信、上传录音或更换模型。
