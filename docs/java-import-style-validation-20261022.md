# Java import 与注解分行整理验收（2026-10-22）

## 修改范围

基于 Git `5f91ad0ebda6aef9b3055534b44fccc0d857e77d` 检查全部 415 个受版本控制的 Java 文件，包括 `outbound-mono`、`backend-java`、`services-java` 和 Java 工具。新增一个解决同名接口冲突的 Java 文件，最终扫描 416 个文件。依赖缓存、生成目录和用户原有未跟踪的 `migration-history-20261020/` 历史材料不属于本次源码整理范围。

- 字段、参数、返回值、泛型、构造调用、静态成员访问和注解中的全限定类型引用统一改为 import。
- 声明注解与被注解的代码分行，包含字段、方法、类、参数及局部变量。
- OpenAI SDK 与 JDK HTTP 类型同名：新增包内 `OpenAiHttpClient` 接口继承 SDK 接口，并使用嵌套类型 import 和静态 import，避免类型同名冲突。接口未增加方法。
- 在单体项目的 Spotless 中增加注解分行步骤，防止格式化时重新合并到同行。复用项目已有 Node.js 和 Shell 工具链。
- 字符串中的类名、反射类名、配置及注释中的文本不作为 Java 类型引用替换。未改接口路径、SQL、业务条件或数据结构。
